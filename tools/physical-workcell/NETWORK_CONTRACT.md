# Persistent body adapter contract

Caller: BodyClient connects once to a loopback BodyService, pins identity, acquires a lease, starts a job, fetches an image challenge, proposes a typed action and dispatches its proposal. An uncertain reply blocks new commands until read-only reconciliation settles it. The original local browser product remains available.

Server owns native Bench, AgentBench, transport command journal and current lease. Client owns pinned identity, immutable outgoing requests, unknown outcomes and downloaded PNGs. The proxy owns only diagnostic transport faults. Native sources remain unchanged.

Protocol: `footwork.body/1`. Identity fields `protocol, adapter_id, body_id, source_sha256, epoch, simulation`. Server restart changes epoch and revokes leases while retaining adapter/body identity. Source SHA pins core sources plus body_protocol.py and body_network.py. Private owned roots live under output. Lifetime server root flock and serialized admission protect concurrency.

Endpoints: GET /identity; GET /state; POST /lease with client_id, expected_epoch, duration_s (0.05..30); POST /commands; GET /commands/<command_id> with client_id, lease_id, epoch, request_sha256 query; GET /images/<challenge_id>. Pinned requests use X-Body-Id, X-Adapter-Id, X-Source-Sha256 headers. No redirects, browser Origin, CORS, arbitrary files or non-loopback bind.

Command exact fields: protocol, adapter_id, body_id, source_sha256, client_id, lease_id, epoch, command_id, operation, arguments. Operations: start_job {job_id,target_zone}; observe {}; propose {challenge_id,action,intent,target_x,target_y}, using null targets for non-move; dispatch {proposal_id}; diagnostic disturb {operation_id,force_x_n,steps} only when enabled. Validate before admission, persist canonical digest and request before effect. Refused admission creates no accepted intent. Budgets: 256 retained commands and bounded JSON/media.

Response envelope: protocol, adapter_id, body_id, source_sha256, command_id, request_sha256, state, result, reason, receipt_scope, recorded_epoch. States completed, refused, unknown, not_seen, not_accepted. completed means known RPC result; dispatch's inner outcome remains executed/refused/unknown. receipt_scope is retained_command_result. Exact ID/digest returns original envelope; conflicting digest refuses. Results are historical, never fresh observations. Known core unknown remains unknown.

Reconcile: query exact original ID/digest. Missing journal plus valid lease is not_seen (inflight remains possible). Missing journal plus expired/revoked lease or changed boot epoch is not_accepted (late request fenced). Accepted missing result is unknown. On boot only dispatch intents with an indexed, hash-verified stored AgentBench result may be reconciled read-only; never call dispatch to repair a receipt. Other missing lower proof remains blocked.

Lease acquire rotates lease ID, even for same client. Other unexpired holder refuses. Check server monotonic expiry and boot epoch inside admission lock. A lease fences new actions; an already admitted native action may finish within its existing local bounds after disconnect or expiry.

Client public API: BodyClient(root, origin, timeout=15), acquire(duration_s=30), start_job(job_id,zone), observe(), propose(challenge_id,action,intent,target_x=None,target_y=None), dispatch(proposal_id), disturb(operation_id,force_x_n,steps), status(), reconcile(command_id=None). Unknown raises Uncertain carrying command_id; expose pending IDs. Known refusal raises Refusal. Persist outgoing request before one send. No auto-resend. Reconcile may resolve not_accepted without dispatching a replacement. Observe downloads exact PNG over HTTP, verifies SHA, replaces top-level image_path only; original observation packet stays bound to server challenge.

Service API: initialize(root, diagnostic_enabled=False); BodyService(root, host='127.0.0.1',port=0, barrier=None), start(), origin, close(). CLI --root --port with optional --initialize --diagnostic and --barrier before_dispatch|after_dispatch. Diagnostic barrier writes root/barrier.json after accepted intent (before/after lower dispatch), then SIGSTOP; harness kills only its owned process. Restart never auto-executes. Proxy API FaultProxy(origin, root), start(), origin, arm(mode, operation='dispatch', delay_s=.2), close(). Modes delay_before, delay_after, drop_before, drop_after, duplicate; one-shot exact payload forwarding, bounded event retention, release proxy lock before sleeps.

Implementation order: server and schemas; independent client/proxy; public-boundary fault tests; source freeze; actual model runner and independent post-trial scoring. Native guards and existing operator files are outside this package's edit scope.
