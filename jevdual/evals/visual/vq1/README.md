# VQ1 development inputs

`development/manifest.json` and `labels.json` are the concrete schema examples for the local qualification harness. There are 24 authored cases, two roles and three related source groups per role. The PNGs are deterministic construction fixtures; capture timestamps are creation metadata and native PID/window IDs are placeholders. No real app, independently collected document or photograph is represented.

The four variants per source group exercise supported, near-miss, ambiguous and text-control inputs. Construction notes and labels stay local and are excluded from provider inputs. This corpus is always ineligible for independent qualification, regardless of its scores. Do not reuse these exposed cases as independent validation.

Run the local commands in [the qualification guide](../../../docs/visual-qualification.md). The example protocol uses proposed experiment settings and illustrative local reservations; it authorizes no paid calls or runtime routing.
