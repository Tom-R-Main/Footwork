## Node redaction and CI

`safeUrl` suppresses UUID, 32-character hex, and word/base64url opaque runs. Recognized credential-route tails are suppressed even when a credential is short or follows an encoded slash boundary. The shared sanitizer is consumed by event metadata and frontend asset serialization.

`sanitizeInventory` constructs a new summary from an explicit schema: own, nonnegative safe-integer `totalCount` and `inlineSvgCount`, plus the six supported `byKind` count keys. Raw summary fields, unknown keys, coercible strings, arrays, and nested credential objects do not pass through. Persisted capture/frontend tests inspect actual written JSON/JSONL artifacts, rather than only helper return values.

The three-line Node CI step overrides the job's `jevdual` working directory to the checkout root and runs the dependency-free inspection suites using available Node. It adds no install or browser launch.

Independent local check: **97 tests passed, 0 skipped** on Node `v22.17.1` with:
