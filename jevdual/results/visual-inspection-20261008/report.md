# Read-only visual target inspection

Implemented `footwork inspect-target` for native operator sessions. It takes a fresh bound-window observation, resolves an observed target, validates its token/frame against the correlated PNG, and records an immutable evidence manifest plus static HTML preview. The preview shows the original unchanged screenshot, an exact CSS target outline, the operation and required postcondition. It makes no provider call, action, consent grant or completion claim.

Actual verification: a run-owned AppKit fixture supplied its process/window binding; real Footwork CLI `look` and `inspect-target` both returned0 through the installed Cua SDK. Native1320x936PNG over660x468window bounds maps the observed button to pixels(52,850)-(408,894). RawPNGhash stayed unchanged, every preview readback check passed, and no fixture effect file was created. The static preview was separately rendered in isolated Chrome and its outline was visually inspected. This verifies the new inspection entry point; application discovery and real Finder/Preview workflows were not requalified.

Evidence: verification.json, preview-render.png and preview/ contain the captured manifest, original PNG and static review. Code hashes and source scope are retained. These are fixture captures, not private user documents. The live surface no longer exists; saved evidence is historical.

Native actionable AX projections report incomplete even when not truncated. Numeric target inspection preserves that warning; label lookup refuses when global uniqueness cannot be established. Secret sessions refuse before driver creation. Truncated/degraded views, missing frames/tokens, missing/invalid PNGs, mismatched paths/dimensions, identity drift and unsafe session paths fail closed. ActualPNG/viewportscale drives coordinates, including downsized captures; the raw SDK retina scale is retained separately. Browser operator capture is explicitly unsupported until exact geometry is qualified. A binding-equality check does not observe the live screen or authorize execution.

Use `footwork look` to obtain the current target ID, then `footwork inspect-target ID --operation click --postcondition "Required observable result" --session SESSION`. The command prints manifest and preview paths. No existing model factories, consent guards or admission settings changed.
