# Reference-repo survey for Footwork inspection

These are source observations from the user-provided local checkouts on October 1, 2026. They inform candidate designs; they are not proof that a transport works against the current Chrome session. The captures already present in the Best-Edit research output remain the live evidence.

| Checkout | Source observation | Footwork implication |
| --- | --- | --- |
| `chrome-devtools-mcp` (`648a667`) | `src/BrowserManager.ts:360-391` reads `DevToolsActivePort` from an existing Chrome user-data directory and forms a localhost WebSocket endpoint. `src/collectors/PageCollector.ts:61-90,386-424` bounds request storage to 1,000 per navigation and retains three navigations. | Reuse the explicit attach idea in a separate persistent transport, but keep the Footwork journal on disk rather than relying on MCP's in-memory request history. Do not start a second controller while the original audit drives the tab. |
| `devtools-protocol` (`8b7f1d95`) | `pdl/domains/Network.pdl:1040-1070` defines bounded Network buffers and `configureDurableMessages`; `:1248-1274` defines `streamResourceContent` and SSE message events. `:1700-1713` states request ExtraInfo may be absent and unordered. `pdl/domains/Target.pdl:235-266` defines flat auto-attach and related-target attachment. | Model redirects and optional events explicitly. Add worker coverage only after a target/session-scoped conformance test. Do not treat missing ExtraInfo as lost traffic. Stream capture needs separate byte caps and redaction. |
| `playwright` (`87291ca60`) | `packages/playwright-core/src/client/browserType.ts:139-175` exposes `connectOverCDP`, including `noDefaults` and artifact directory options. `client/tracing.ts:108-145` offers HAR capture with `attach`, `embed`, or `omit` content and URL filtering. | A private Playwright trace/HAR can cross-check selected runs, but may collect raw values and is not a substitute for Footwork's value-minimized journal. Keep it an opt-in calibration artifact. |
| `mitmproxy` (`d9a72da7b`) | `mitmproxy/http.py:247-259` requires streaming to be selected in the request/response-headers hook. `proxy/layers/http/__init__.py:442-471` forwards response chunks as they arrive. `addons/server_side_events.py:8-23` warns that SSE can be swallowed without streaming. | A proxy could test an unresolved stream/worker blind spot, but changes the browser's network path and trust setup. Defer until CDP coverage is measured; use only scoped, private runs. |
| `httptoolkit` (`bb579a8`) | This checkout is the umbrella README and security policy; `README.md` points to separate UI, server and Mockttp source repositories. | It supplies a candidate ecosystem, not enough local implementation code to justify a Footwork adapter. Do not claim specific capture behavior from this checkout. |

**Current build choice:** use the existing sealed CDP journal as the primary instrument, and add a coverage audit before experimental comparison. The live Symbolic route packet with an explicit `event-buffer-truncated` gap must stay limited even though many requests were reconstructed. A separate long-lived CDP transport is a candidate to close the tool-call continuity gap, but it needs scoped attachment, ownership checks, worker tests, durability and a real cross-call calibration before use.
