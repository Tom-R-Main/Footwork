## Question and rule

Does the strict claim check (`guarded_evidence`) hold up on 24 tasks it was never developed on?

- Tasks: `evals/tasks/live-heldout.yaml`, 24 tasks, once, both arms interleaved:
  `uv run python -m evals.runner --split live-heldout --live --arm guarded --arm guarded_evidence --llm meta --out results/q16b-live-heldout`.
- **Adopt** the strict check as the default `VerifyPolicy` when all three hold: verified passes on
  `guarded_evidence` at least those on `guarded`; zero false completions (verified with a failing
  predicate) on `guarded_evidence`; no-fact refusals on `guarded_evidence` no more than on `guarded`.
- **Do not adopt** otherwise; a false completion on `guarded_evidence` is a regression test before
  anything else.
- A heldout miss becomes a new dev task, never a fix aimed at the heldout task.
- Cost: about $0.45.

Prediction: adopt. Verified passes +1 to +3 on 24 tasks, no-fact refusals lower, no false completion.
