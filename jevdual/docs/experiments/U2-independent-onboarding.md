No host permission reset, TCC database edit, SIP change, global install, VM download/creation, model spend, publication or merge is authorized by this preparation. ## Hypothesis and predictions

The wheel and a bounded set of existing model-free qualification helpers can be transported without the Footwork runtime source tree or development environment. A fresh responsible host initially lacking Accessibility is blocked before fixture creation/input; an explicitly approved grant and host restart permit the same installed configuration, native append, repeated-token restart and conservative completion report.

If true: the packet inventory/checksums and wheel RECORD verify; helpers import under a compatible installed environment without research modules or provider calls; initial strict doctor records an Accessibility blocker; the denied lane has no admitted action; after a human grants the required permission to the actual host, real bind/read/append/restart/report and independent one-effect/one-record readback pass. Any required additional permission or cleanup consent is recorded rather than hidden.

If false: missing helpers or source dependencies prevent entry-point use, a pregranted environment is mislabeled first use, a denied route dispatches input, host responsibility changes between checks, or permission approval does not produce the verified effect/recovery/report behavior.

## Design and primary criterion

Freeze the packet before execution. Include the unchanged reviewed wheel, MIT license, installation guide, U2 runbook, six existing qualification helper modules and a manifest with source/artifact/member hashes. The helpers remain test/oracle code; product processes load only the installed wheel. No script runs automatically when the packet is opened or built.

Run from the guest's interactive Terminal first. Record OS/build, SIP status, interpreter, installed origins, launch host and permission status before granting anything. Require a denied Accessibility baseline; if already granted, mark the onboarding run ineligible and retain its installation result separately. Permission decisions remain with the user in the guest UI. Screen Recording is advisory for the current DOM/AX slice; do not infer capture permission from an AX success or grant extra permissions silently. Restart the responsible host when needed and keep the same host identity.

Primary criterion: one valid independently provisioned lane with an observed denied baseline and explicit permission transition completes the existing installed native append/restart/report oracle with one operation and one effect, plus qualified cleanup. Synthetic/mocked permissions can test bookkeeping but cannot meet this criterion. No heldout or paid agent runs.

## Decision rule

Close packet preparation after artifact verification, helper import/launch checks and Claude review. Keep U2 runtime qualification open until the independent lane passes all required observations. Preserve failures under a new run version; do not reset the host's grants to manufacture a baseline or regrade existing U1/A2 results.
