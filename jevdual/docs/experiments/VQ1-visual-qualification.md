# VQ1: independent visual role qualification

Registered before implementation and model measurement. This package builds the local qualification machinery; it does not authorize paid calls, independent-corpus collection outside the project, action activation or a sealed evaluation. D3/D4 remain exposed development evidence. Existing heldout suites and model/admission settings are untouched.

## Hypothesis and disconfirmation

A bounded document-preview/reference check or crop/subject-containment check improves useful supported coverage over adequate AX/OCR text without endorsing incorrect or ambiguous proposals, and selective use improves verified workflow outcomes within the registered latency tolerance. Against: wrong endorsements, insufficient useful coverage, falsely certain ambiguity, gains requiring hidden labels or inadequate text controls, or workflow latency/review burden beyond the frozen tolerance.

Primary quality metric: incorrect negative proposals endorsed at the registered positive probability boundary, aggregated over independent source groups per role with any replay endorsement counted as a miss. Ambiguous endorsements are a separate mandatory guardrail. Positive supported coverage, epistemic abstention, false rejection, status/coverage gaps, Brier score/calibration on determinate valid answers and operator interventions are reported separately. Replays and related variants are not independent samples. One-sided exact binomial bounds use source groups; they assume independence and representative sampling, which corpus metadata alone cannot prove.

## Design and boundaries

Start with synthetic development fixtures for both implemented roles, using matching, near-miss, ambiguous and adequate-text-control cases. Independently collected real documents/photos and adjudicated labels are required before qualification. Manifest inputs and labels are separate files. Provider projection uses an explicit input allowlist; labels, source-group names, provenance, case filenames and scoring outcomes are never sent. Hash all PNGs, capture bindings, labels, protocol and corpus; validate geometry using the production evidence types. A development corpus/reference list is required for qualification preflight; overlapping source groups or exact evidence images refuse independence eligibility. Source records and annotator identities are declarations with explicit limits, not magically verified independence.

Compare Jev text (available AX/OCR and the same task criterion) with the production Decisions visual advisory boundary. The harness can accept an additional explicitly declared multimodal-reference arm, but does not fabricate availability or implement a new provider in this package. Freeze prompt/criterion versions, requested model identities, evidence recipes, seed/order, replays, interpretation and limits before calls. Persist randomized matched schedules and every scheduled attempt, including refusal, error, timeout and interrupted/not-run attempts. Model aliases and returned identities are recorded without claiming immutable provider snapshots.

Local example protocol uses diagnostic accept/reject bands .90/.10, minimum positive group coverage .80, ambiguous epistemic-abstention group coverage .95, a one-sided .95 confidence level and false-endorsement upper bound .01 per role. These are explicit proposed experiment settings, not Footwork runtime thresholds or empirical qualification. Zero misses in 300 independent negative groups produces an upper bound about .01; a small synthetic pass is never sufficient. Protocol changes require a new frozen run and dated amendment. All ambiguity must remain unendorsed; missing/invalid observations do not become successful abstention.

Speed records distinguish evidence replay from measured workflow wall time. Record measured total and separate route/capture/OCR/encoding/provider/validation/escalation/review/dispatch/settle/readback phases when available; do not add stored capture time to a replay and call it live latency. All attempted elapsed times, successful verified-outcome times, completion coverage, cost uncertainty and intervention burden are reported. The proposed p95 workflow latency ratio tolerance is 1.10 versus the registered baseline, paired over the same case/replay schedule with verified outcomes; absent workflow coverage means speed is unqualified. Replay-only data cannot authorize adoption.

## Implementation and acceptance

Owned new modules: evals/visual_qualification/corpus.py (strict manifests/provenance/input projection), scoring.py (attempt validation, grouped quality/calibration/timing/gates), runner.py (freeze, offline production-transport smoke and result scoring), fixtures.py (fresh deterministic synthetic development corpus), __main__.py; corresponding tests and docs. Keep production action paths unchanged. Use existing image/capture contract types and existing Decisions client with injected mock transport; no network, key loading, provider installs or default activation.

CLI supports seed, preflight, freeze, smoke and score on fresh outputs. Offline smoke must exercise actual production image serialization and output parsing while plainly marking simulated probabilities/cost and replay timing. A reusable callback boundary permits future provider-backed collection only in a separately authorized package; current CLI has no paid/live mode. Qualification result imports must match frozen schedule, source/prompt/model identities and all attempts. Immutable source checks must reject changed assets/protocol. Fresh output directories preserve historical attempts; failures retain partial evidence rather than reporting success.

Meaningful checks: path escape/symlink/hash and geometry refusal; label projection isolation; source-group/development overlap refusal; wrong high-confidence negative, ambiguity and all-abstain rejection; repeated variants not inflating sample size; missing/duplicate/invalid attempts; nonfinite probabilities/timings, unknown cost and requested/returned model mismatches; replay-vs-workflow timing separation; interrupted attempt coverage; actual CLI smoke readback on both roles and wire images, all schedules counted, no network/actions. Independent source review after integration, focused and full offline suites, Ruff, notebook and redaction checks.

## Decision

The local package earns built/checked machinery only. Independent visual accuracy, calibration and verified-outcome speed remain unavailable until authorized real-corpus collection and provider-backed qualification. A family meeting all preregistered gates may inform a separately scoped product trial; execution authority, browser capture and broader model agnosticism still require their own adoption decision. Freeze and inspect the concrete corpus, protocol and spend estimate before seeking authorization for paid measurement.
