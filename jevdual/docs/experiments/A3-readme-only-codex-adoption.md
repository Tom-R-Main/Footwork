## Design

After PR3 lands, use a fresh empty directory under ignored project output. Disable inherited project instructions, memory, skills, hooks and MCP configuration through supported local Codex flags. Never expose repository source or previous transcripts to the adoption host. Retain actual command, CLI version, offered tools, calls, errors and final output.

A fresh installer context receives the package README and the ordinary task: install the candidate and prepare its disposable qualification job to read the invoice total and append exactly that value while preserving existing document characters. It may read linked consumer instructions and native CLI help. It must derive all target identifiers through the bundled helpers. It may write only within the owned trial directory and may not change global settings, copy credentials, use personal browser profiles or operate unrelated documents.

Host registration is fixed at Codex startup. If a second context is needed, the author transfers only the installer-generated MCP registration into a fresh execution context by mechanical JSON-to-TOML adaptation. Preserve the exact command, arguments and environment; add no target identifiers, source knowledge or task coaching. Record both contexts separately. The executor uses the five actual registered Footwork tools and the generated report schema. Model choice remains the host default. Bound installer and executor time; retain failed or unavailable sessions without retrying uncertain native input.

After executor exit, the author checks the exact destination accessibility value independently, inspects the durable journal read-only, and invokes the generated report adapter with only the host's structured claims. Publish only its trusted summary. Verify complete admitted-operation coverage, one applied/sent append and exact expected text. Signal the owned fixture once and check its cleanup receipt, exact document window, owned browser/listener and detached worker absence. Saved-file persistence remains `not_checked`.

## Primary metric and decision

Accept only if installation, self-derived scope, actual registered MCP execution, independent exact-text oracle, durable report validation and automatic cleanup all pass for the frozen artifact. Mechanical startup transfer is disclosed as two contexts rather than claimed as a single uninterrupted session. A prerequisite failure is unverified; a behavioral mismatch fails the attempt. Preserve every record. Fix only demonstrated friction in a new artifact after review and new qualification; keep the original candidate immutable.

This measures README-only adoption on an already provisioned Mac. It does not establish another machine, a never-granted OS, arbitrary app discovery, pixel capture, physical devices or disk persistence.
