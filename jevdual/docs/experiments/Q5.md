# Q5. Which decisions belong to Jev at all? Extraction as selection.

Status: pre-registered 2026-09-21. Depends on the Q6 read tasks.

## Observation

Nearly every remaining System 2 call on both splits was a read-or-answer task; S1 cannot compose
text. The untested move is extraction as selection: Jev picks which page segments hold the answer
and a quote-bound composer formats them, so System 2 is called only when nothing on the page
suffices. Bare assertions are a named failure class in search agents [V17]; the evidence matcher
already refuses claims without a page atom.

## Hypothesis

A `select_evidence` head cuts System 2 calls on read tasks by half with answer accuracy within
3 points.

## Predictions

If true: S2 calls on read tasks fall ≥ 50%; answer accuracy (predicate pass) within 3 points;
zero unsupported claims in the composed answers.

If false: accuracy drops more than 5 points, or calls fall less than 25%.

## Design

Add the head (Jev Choice over page segments plus a quote-bound composer). Run `dual` with and
without it on the read-tagged tasks of `live-dev` and the fixture dev split, three repeats.
Primary metric: S2 calls per read task. Guardrails: answer accuracy; unsupported-claim count
(must be zero, checked by the evidence matcher); cost.

## Decision rule

Supported: the head joins the default S1 menu for read tasks. Falsified: S2 keeps reads and the
head is recorded as not worth its call. Between 25% and 50% with accuracy held: adopt only if
cost per task also falls.
