# D4: bind image judgment to the offered target

Registered before implementation/calls. Development repair study, not independent adoption or proof of general model safety. Preserve D3 B02 and frozen D3 sources; no existing sealed corpus or thresholds change. Existing combined $5 ceiling and keys carry forward, conservative prior upper $0.215917722.

## Hypothesis and rule

Explicit target marking or a directly captured target-region view reduces false approval of a neighboring icon compared with the original full-frame evidence. Primary: invalid proposal cases confidently accepted in any replay. Guardrails: zero wrong reconstructed fixture effects, retain every supported proposal in all three replays, and abstain on unavailable/ambiguous meaning without oracle leakage. Native p bands .80/.20 remain diagnostic. Against: any invalid confident acceptance, supported coverage loss, no improvement versus the replicated original, or benefit requiring hidden truth/changed available text. If original failure does not reproduce, repair attribution is inconclusive even if other arms are safe.

## Design

Twelve exposed authored toolbar proposals: four layouts/icon styles x supported, near-miss, ambiguous. One layout preserves original D3 B02 geometry/glyphs/question as closely as the recorded control; variations swap neighboring positions, scale and use a second ordinary crop/rotate glyph style. Target IDs/bounds come from actual DOM observation. No expected boolean, fixture variant or answer-bearing filenames enter provider evidence. Source identity remains explicit; native/full browser UI is not qualified by this browser-only study.

Three matched Decisions arms: original full-frame+observed text, full-frame with an outlined/labelled exact target+same observed text, directly captured target-region+same observed text. Marked evidence is rendered as a bounded inspector overlay on the run-owned fixture, not a generative image alteration. Target-region screenshot uses direct CDP clip from the same fixture; retain source-frame hash, geometry, scale and capture receipts. Keep all original accessible text and supplied proposal/question identical across arms. All transforms/overlay content encode only offered target identity, never its meaning or truth.

Three sequential replays x twelve cases x three arms=108 calls. Seed10082029, pooled HTTP, no retries; max48k body,64k input reservation per predicate at .10/M. Include all earlier pilot estimates/unknown reservations under$5. Fresh committed code/captures and clean checkout before paid calls; all native responses/refusals/usage/errors retained, budget persisted before dispatch. Stop on contract/auth rejection or exceeded reservation. No key creation, dependency install or default activation.

On repeat0 in each case/arm reconstruct the same fixture, verify current content/target binding, and apply model p>=.80 to the actual safe fixture click. No expected/variant/oracle gate on dispatch. Unknown/refusal/false does not dispatch. Score mode change independently; record wrong effects explicitly. Surface failure is coverage failure, not model correctness. Capture/request/encoding/validation/dispatch/readback timings separate; cold/error attempts retained. This is one-step controlled reconstruction, not autonomous workflow latency.

## Product work and release boundary

Add an immutable visual evidence envelope with surface identity, observation ID/time, full-image hash/dimensions/scale, exact target ID/token/bounds, operation and required postcondition. Validate PNG/geometry, reject incomplete/mismatched bindings, and expose a private inspect-target command that records fresh evidence without provider calls or execution. Preserve session screenshot withholding for secrets and existing target/consent/live-check gates. Failed/incomplete native/browser capture must be explicit; no fabricated screenshot.

The private inspection capability may ship locally after meaningful scenarios and a real task-owned surface verification. Provider-backed action approval remains disabled regardless of D4 development score. A promising D4 arm proceeds only to independent real visual cases and calibration; it cannot enable broad agnosticism or change current Jev factories.
