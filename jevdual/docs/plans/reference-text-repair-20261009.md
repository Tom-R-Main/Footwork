The repair combines exact optional-value semantics, independent insertion capability, fresh preconditions and explicit public text behavior. It preserves the legacy native separator rule, exposes `append_separator` per offered target and keeps supplied text literal. Footwork already has the stronger empty-value fallback: absent AXValue means empty only if AXNumberOfCharacters proves zero. No equivalent was found in inspected Cua/arc-cua source; Footwork must qualify it with its own tests.

Cua's content-derived label can change after an empty append. Readback now uses the scoped document, AX role and unique original field frame; changing role/frame or introducing matching ambiguity stays unknown and blocks redispatch. This is current field evidence, not durable incarnation or disk-persistence proof.

Sixteen public capability scenarios drive the real backend, service, NativeBridge, menu parser and AX value/resolve/insert logic while simulating only external Cua/Mac primitives. They cover literal whitespace, proven empty, unreadable/readonly/secure/ambiguous fields, lost setter permission, stale document/content and post-send identity loss. Fresh external-host qualification is separate from offline proof and original C1.
